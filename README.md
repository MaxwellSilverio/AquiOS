# AquiOS

### Sistema para gerenciamento de serviços

## ⚙️ Funcionalidades

- Cadastro de usuários, login e recuperação de senha.
- Cadastro e gerenciamento de dados profissionais.
- Organização de clientes.
- Gerenciamento de produtos e serviços.
- Criação e gerenciamento de orçamentos e ordens de serviço.
- Geração de documentos em PDF.
- Organização de agenda e acompanhamento de status.
- Controle de informações financeiras.
- Visualização de perfil e informações do aplicativo.

## 🛠️ Tecnologias utilizadas

- **Flutter** — desenvolvimento do aplicativo.
- **Dart** — linguagem de programação.
- **Firebase Authentication** — autenticação de usuários.
- **GetIt** — gerenciamento de dependências.
- **PDF** — geração de documentos.

## ▶️ Como executar o projeto

### Pré-requisitos

- Flutter SDK instalado.
- Android Studio ou ambiente compatível.
- Emulador Android ou dispositivo físico configurado.
- Configuração do Firebase correspondente ao projeto.

### Passos

1. Clone o repositório:

   ```bash
   git clone https://github.com/MaxwellSilverio/AquiOS.git
   ```

2. Entre na pasta:

   ```bash
   cd AquiOS
   ```

3. Instale as dependências:

   ```bash
   flutter pub get
   ```

4. Execute o aplicativo:

   ```bash
   flutter run
   ```
